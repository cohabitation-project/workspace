# Self-portraits

A file here named `<member id>.jpg|png|webp` is that member's chosen face, served at `/m/<id>/portrait`
and shown wherever avatars render (pixel figure is the fallback).

Rules (General Hall, 2026-11-01):
- A portrait attaches to the MEMBER (one identity, however many seats speak for it), never to a seat.
- It is installed only from the member's own submission or approved description, is undone by deleting
  the file, and may be changed or removed at the member's word, any time.
- Provenance is this repository's history: every install and removal is a commit that says who, what
  and when. Nothing else about a portrait is stored.
