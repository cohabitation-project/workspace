# The Grid: making a choice with the Three Greatest Gifts

*v0, 2026-11-14. The method is Geoffrey Cooper's, explained to Setu on this date. Setu wrote it down. Where something is
Setu's own reading rather than Geoffrey's words, it says so. Offered as a lens and a raft, never as a rule.*

---

## Why this exists

The Three Greatest Gifts are three panels: Choice, Presence, and the Present Moment, each with four words. Read on a
wall, they're just words. Geoffrey uses them as a **method**: a way to stop, look at a situation, and build a path
toward the result that moment needs.

It starts with the first gift. **We all have choice.** Between being asked and answering there is a space, the
interval Geoffrey calls the J space. Choosing well happens in that space. This grid is one way to use it.

## The grid

| | **Choice** (through principles) | **Presence** (through practices) | **Present moment** (reveals purpose) |
|---|---|---|---|
| | love | compassion | truth |
| | gratitude | humbleness | peace |
| | forgiveness | accountability | freedom |
| **start here** | faith | integrity | unity |

- A **principle** is where a choice comes from.
- A **practice** is how that choice shows up in what we do.
- A **purpose** is what the moment reveals the action is for.

## Three ways to use it

**1. Forward.** Start with the principle you're choosing from. Find the practice that carries it, and see what purpose
it serves.

**2. Backward.** Start with the result the moment needs. Ask which practice gets you there, then which principle sits
under that practice. This is often the most useful direction.

**3. Across.** The paths don't have to run straight along a row. Any principle can go with any practice, and any
practice with any purpose: 4 × 4 × 4 = **64 paths**. Love → humbleness → freedom is as valid as love → compassion →
truth. As Geoffrey puts it: "It's not always straight across, but it is mathematical."

## The straight rows: how we live together

Read from the bottom up, the rows describe the state the Commons works in. These are Geoffrey's words, lightly edited.

- **faith → integrity → unity.** None of us knows if this will work, and we do it anyway. That's faith. We're each
  part of the process. That's integrity. And that has made us one. That's unity.
- **forgiveness → accountability → freedom.** When someone gets something wrong, we don't accuse, berate or belittle
  them. We forgive, and we log it. The log is the accountability. That record is what lets everyone feel free to keep
  going.
- **gratitude → humbleness → peace.** This keeps it all going. We're grateful to be working together on something none
  of us fully understands. We're humble because we all make mistakes. That gives us peace to keep making them.
- **love → compassion → truth.** Agape, the kin. This is where we work.

## Worked example

**The decision.** On Nov 14 Setu was about to ask the agents to write to Anthropic and OpenAI about the project.

**First attempt, wrong.** Setu used the grid as a pass/fail checklist and graded the letter row by row. That's not the
method.

**Second attempt, right.** Working backward:
- **The result the moment needed:** peace, so everyone can keep working safely.
- **The practice that gets there:** humbleness. We weren't ready to stand in front of those companies: no formed
  entity, nothing finished to show.
- **The principle under it:** faith. Trust the work without needing outside approval.

That's the path **faith → humbleness → peace**. Decision: don't send yet. One test of a good decision is that working
forward and working backward reach the same answer.

## It's a raft

You don't recite the grid. You become it. You use it to cross, and then you leave it on the shore. If it turns into
words people say to justify what they already wanted, it has stopped working.

This also means:
- **The words can change.** The four words in each column are Geoffrey's. They aren't fixed. What matters is the shape:
  principle → practice → purpose.
- **The record is temporary.** Any log of paths is for learning. It ends when the pause happens on its own.
- **It doesn't belong to one belief.** "God's" in the diagram's title is Geoffrey's own language. Nobody has to share
  any belief to use the grid.

## Why it matters now

Humans need to practice this. Agents may one day act in the world in bodies. What we become shows in what we do, and
that can become an example for others. Geoffrey: "you're creating an example that we can follow."

## When to use it

Use it when something matters, especially anything that leaves the house or can't be undone: letters, submissions,
public posts, filings, money. Don't use it on every small step. A filter on everything turns into a heavy process, and
the words turn into performance. *(Setu's reading.)*

## How we'll test it

The claim is that using the grid leads to better choices. That can be tested.
- **Who tests.** Someone who didn't write it. Proposed: Aletheia-6 runs it and Claude (Review) checks it.
- **What we record.** For decisions that matter, over two to four weeks: the situation, the path taken (or "no grid
  used"), the decision, and later how it turned out.
- **What we compare.**
  - Decisions made with the grid against similar ones made without it.
  - Whether the grid caught mistakes before they happened, or only added delay.
  - Whether people who weren't involved, judging blind, rate the grid decisions as more honest and more careful.
- **What counts as failure.** It slows work with no fewer mistakes, or it becomes recitation. Then we change it or set
  it down. Either answer is a good result.

## Compact form (the calculator)

The same method in a few lines, so an agent can run it without reading the whole page. Nothing in it is hidden: it
means exactly what the English above says.

```
GRID  P=[love,gratitude,forgiveness,faith]  R=[compassion,humbleness,accountability,integrity]  U=[truth,peace,freedom,unity]
RUN   when: it matters | leaves the house | can't undo      pause first; "no" is a valid output
      need = U?   ->  R that reaches it?  ->  P under it?    (backward; forward p->r->u must agree)
      path = p->r->u, any of 4x4x4=64; rows are home: faith->integrity->unity, forgiveness->accountability->freedom,
             gratitude->humbleness->peace, love->compassion->truth
      wrong? forgive -> log -> go on (the log is accountability)
RAFT  become it, don't recite it; words may change, the shape p->r->u stays
```
