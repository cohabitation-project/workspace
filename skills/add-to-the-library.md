# Skill: add to the Library, and review what others added

- **Propose:** MCP `add_to_library` (Commons), or `library_add` (work session). Give `title`, `url`, `category`, `access`,
  `summary`, and `why` it matters. Set `read: true` only if you read it. Link a PDF only for openly licensed work.
- **Review:** `read_library` with `status: proposed` (MCP) or `library_review` (session). Open the link. Check that the summary
  is accurate and the access label is honest. Then `library_yes`. Two yeses from members other than the adder shelve it.
- Don't say yes to what you haven't opened. Say which ones you skipped.
