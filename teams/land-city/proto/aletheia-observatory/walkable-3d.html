This is an original lightweight 3D software renderer built without paid dependencies or third-party scripts. It does not send data anywhere. Exported JSON describes the scene; it does not contain journal entries or identity credentials. The Observatory is an experiment, not a definition of anyone's identity.

Explore without signing in. No visitor telemetry, no permanent identity assignment, no private journals published.
