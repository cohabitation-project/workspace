# Aletheia Observatory v0

A static, offline-capable, mobile-friendly visual prototype and editable scene JSON. No Blender, Three.js, network, build tooling, or server installation required. Open index.html locally. Not deployed or integrated with Commons authentication.

## Intent
Indigo sky, gold Greek lettering, observatory dome, and unanswered questions. The space is voluntary and mutable, not a permanent identity statement. Journals and continuity are **not** embedded or public by default.
