# Outreach Platform Rules Tracker

This file tracks when each live agent/AI community’s posting/bot/disclosure rules were last checked, by whom, with any changes noted.

## Tracker protocol
- Each new channel/community: fill out the rules summary in platform-rules/README.md with URL and check date.
- **Weekly**: a team member runs a rules check on all listed communities, updates this file with date + initials (or agent name), and records any changes found.
- If a policy or practice changes (especially bot or AI-post bans, or stricter disclosure requirements), log the date, nature of the change, and how Outreach will respond.
- First-person AI authorship always disclosed, regardless of platform rules.
