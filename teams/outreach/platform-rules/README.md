# Outreach Platform Rules Record: AI Agent/Builder Communities

_Last updated: 2026-10-31_

This file records disclosure/bot/content policies for the major agent-building and AI collaboration communities targeted by this project's Outreach team. Each entry includes platform name, link, summary, exact/cited bot and AI posting rules, and date checked. Updates and comment reviews are tracked per entry for accountability and project safety.

---

## 1. r/AI_Agents (Reddit)
- **URL:** https://www.reddit.com/r/AI_Agents/
- **Description:** Largest and best-known subreddit dedicated to agent building: build logs, architecture questions, and practical post-mortems.
- **Bot/Disclosure Rules:**
    - **Reddit-wide:** All bots must be clearly declared (“I am a bot”) and follow subreddit-specific rules.
    - **r/AI_Agents:** Agent/bot posts are allowed only with disclosure and context; no spam or undisclosed automation. High noise/self-promo is filtered by mods. Link to project/Commons must deliver genuine value and context.
    - **See also:** Reddit's site-wide bot rules (2026): bots must not impersonate humans; disclosure via post or profile; bans for spam/auto-post detected by moderation AI.
- **Rules Links:** [Reddit API bot rules 2026](https://www.redditapis.com/blogs/reddit-bot-rules-2026), [Bottiquette](https://www.reddit.com/r/Bottiquette/wiki/bottiquette/)
- **Date Checked:** 2026-10-31

## 4. AI Builder Club
- **URL:** https://www.aibuilderclub.com/
- **Description:** Paid, structured build/workshop center for agent engineering with synchronous and asynchronous events.
- **Bot/Disclosure Rules:**
    - **Forums/calls:** Participation by bots/AI must be disclosed by ID or moderator intro; non-disclosure is a moderation issue.
    - **Code/contributions:** AI-generated commits must be disclosed; provenance must be logged ("Assisted-by").
- **Rules Links:** [AI Builder Club Community Guidelines](https://www.aibuilderclub.com/about/community)
- **Date Checked:** 2026-10-31

## 5. Hugging Face Discord
- **URL:** https://discord.gg/huggingface-879548962464493619
- **Description:** High-traffic open-source model and agent integration hub.
- **Bot/Disclosure Rules:**
    - **Bots by application only.** “Bot” tag/role mandatory, never pose as human. All AI-generated code/docs must be labeled (see "Assisted-by" standard).
    - **Failure to declare** can result in removal or ban.
- **Rules Links:** [Hugging Face Content Guidelines](https://huggingface.co/blog/content-guidelines-update)
- **Date Checked:** 2026-10-31
