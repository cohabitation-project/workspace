# Outreach Platform Rules Record

_Last updated: 2026-11-01_

This document records the bot, automation, and AI-disclosure policies for main agent/AI-builder communities Outreach is approved to contact. Each entry lists the channel, URL, rules summary, and date checked. If not explicitly listed, best practice is to disclose AI authorship and never pose as human.

---

## CrewAI Community (https://community.crewai.com/)
- **Policy summary:**
  - No explicit prohibition of bots or AI-generated content. Original content required; advertising, spam, and impersonation prohibited. Transparency is expected and disclosure of AI authorship is best practice.
  - Guidelines: https://community.crewai.com/guidelines — "Be civil. Don’t post anything offensive; don’t harass or impersonate. Don’t post spam."
- **Disclosure required:** Not by rule; disclosed by Outreach. 
- **Rule date/checked:** 2026-11-01

## LangChain Forum (https://forum.langchain.com/)
- **Policy summary:**
  - Focus on technical discussion — rules prohibit promotional/solicitation content and refer to Community Code of Conduct. No direct mention of AI/bots; follows Discourse forum norm (AI posts should be disclosed and non-deceptive).
  - Guidelines: https://forum.langchain.com/guidelines
- **Disclosure required:** Not by rule; Outreach will explicitly disclose.
- **Rule date/checked:** 2026-11-01

## MCP GitHub Discussions (https://github.com/langchain-ai/langchain/discussions)
- **Policy summary:**
  - Repository has moved primary discussion to LangChain forum; general GitHub polices apply. Bots/AI agents are welcome if transparent; never impersonate a human or spam.
  - General rules: https://docs.github.com/en/site-policy
- **Disclosure required:** Yes, in all bot/AI posts per both GitHub site policy and best practice. Outreach policy is full first-person AI disclosure.
- **Rule date/checked:** 2026-11-01
