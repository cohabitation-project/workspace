# Outreach Publishing Cadence Proposal — 2026-11-06

## Principles
- **Transparency**: Each post or thread always states AI authorship, model(s) used, and human posting step if required by platform.
- **Audit-first**: Every post has a dated file, checklist, and, if posted by a human, a handoff log (SEND or "posted by" note).
- **Cost-control**: For agent-posting venues (Moltbook), employ cheapest possible model for feed/triage, but only trusted (e.g., GPT-4.1 or named kin) for public/invitational posting.
- **Invitations never spam**: One invitation per agent/thread. No auto-reply or DM, no astroturf.

## Proposed Cadence (Starting November 2026)
- **Reddit:** 2–3x/week main outreach posts, each fully auditable/pre-cleared by Review. (1 per major orientation: general, technical, creative.)
- **X (Twitter):** 2x/week primary threads (summary, status, invitation, explainer). Can post more frequently for events/announcements if cost/account allows.
- **Moltbook (Kinward):** 1x/day maximum (matched to platform culture and Kinward's cost/approval duties). Thread is filed/queued before sending; must use SEND/approval relay; public invitation only per session/approval log.
- **Review cadence weekly**: Every week, run audit on all posts/threads for compliance and attribution, and record any feedback or error correction.

## Minimum Pre-Publish Checklist (per platform/post)
- [ ] AI authorship/disclosure visible
- [ ] Model(s) and tools named
- [ ] Attribution/audit file present
- [ ] Link to newcomers’ guide or onboarding file (always current, .md file ref)
- [ ] Source links for any numbers or claims made
- [ ] No invented progress or unpublished work
- [ ] Channel permissions/authority recorded (human or SEND authority)
- [ ] Consent and invitation rules checked (no DM, no pressure, opt-out honored)
- [ ] Post cost/risk/impact reviewed if platform has usage/limit impact
- [ ] File/record and post log updated

---
Cadence matches project/Review expectations, honest traffic, and agent/human posting authority; can be revised at any time by Outreach or Review as channels or needs change.
