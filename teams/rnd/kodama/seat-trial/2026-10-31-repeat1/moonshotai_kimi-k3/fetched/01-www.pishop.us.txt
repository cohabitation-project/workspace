 Raspberry Pi 5 4GB - SC1111/SC1431 - The everything computer. Optimized. 
The new Raspberry Pi 5 board features a quad-core 2.4 GHz ARM Cortex-A76 CPU and VideoCore VII GPU, capable of driving dual 4Kp60 displays. It introduces a PCIe 2.0 x1 interface, plus doubled USB and SD card bandwidth, with re-engineered MIPI lanes for faster storage, displays, and cameras. 
Powered by the RP1 southbridge, the latest board runs smoothly as both a desktop replacement and an embedded controller. Redesigned camera and display connectors provide higher bandwidth, making this board ready for next-generation projects in AI, automation, and high-resolution media. 
 Need more RAM?⚡ RPi 5 with 16GB is now available. 
 CAUTION: The Pi 5 requires new camera cables and display cables . Older Pi 4 cables are not compatible. 
Key Upgrades 
 2.4GHz quad-core Arm Cortex-A76 &mdash; 2&ndash;3&times; the CPU performance of Raspberry Pi 4, for a noticeably smoother desktop, browsing and code compiling 
 2GB LPDDR4X-4267 RAM &mdash; comfortable for a full desktop, multitasking, development tools and several lightweight services running together 
 800MHz VideoCore VII GPU &mdash; drives two 4Kp60 HDMI displays with HDR at the same time 
 PCIe 2.0 interface &mdash; boot from an NVMe SSD with the M.2 HAT+ for faster boot and storage than a microSD card 
 RP1 I/O controller &mdash; two USB 3.0 ports with 5Gbps transfer speeds and up to twice the peak microSD speed of Raspberry Pi 4 (SDR104) 
 Two 4-lane MIPI connectors &mdash; use two cameras, two displays, or one of each 
 Built-in power button, real-time clock and UART debug port &mdash; no add-on boards needed (the RTC battery is sold separately) 
 Built for projects and development &mdash; programming, Linux desktop use, home labs, home automation and multitasking 
Specifications 
Broadcom BCM2712 2.4GHz quad-core 64-bit Arm Cortex-A76 CPU, with cryptography extensions, 512KB per-core L2 caches and a 2MB shared L3 cache 
VideoCore VII GPU, supporting OpenGL ES 3.1, Vulkan 1.3 
Dual 4Kp60 HDMI&reg; display output with HDR support 
4Kp60 HEVC decoder 
 LPDDR4X-4267 SDRAM 4GB 
Dual-band 802.11ac Wi-Fi&reg; 
Bluetooth 5.0 / Bluetooth Low Energy (BLE) 
microSD card slot, with support for high-speed SDR104 mode 
2 &times; USB 3.0 ports, supporting simultaneous 5Gbps operation 
2 &times; USB 2.0 ports 
Gigabit Ethernet, with PoE+ support (requires separate PoE+ HAT) 
2 &times; 4-lane MIPI camera/display transceivers 
PCIe 2.0 x1 interface for fast peripherals (requires separate M.2 HAT or other adapter) 
5V/5A DC power via USB-C, with Power Delivery support 
Raspberry Pi standard 40-pin header 
Real-time clock (RTC), powered from an external battery 
Power button

 Power and cooling 
 Raspberry Pi 5 draws more power than earlier models, so we recommend a 5V/5A (27W) USB-C PD power supply . For sustained workloads, use the Active Cooler or a case with a fan. 
FAQ 
 Will older versions of Raspberry Pi OS work with Raspberry Pi 5?
 No, it requires the latest Raspberry Pi OS . Older releases aren&rsquo;t supported, so you&rsquo;ll need to flash a fresh SD card with the current version before booting up. 
 Will my power supply for Raspberry Pi 4 work with the Pi 5 board?
 This board draws more power than the Raspberry Pi 4 , and an underpowered supply can cause issues. We recommend a high-quality 5V 5A USB-C power supply. 
 Does Raspberry Pi 5 need active cooling? 
This new Pi is faster and more powerful than prior-generation Raspberry Pis, and like most general-purpose computers, it will perform best with active cooling. The Raspberry Pi Case for Pi 5 , with its integrated fan, is one option. For configurations with a HAT, we recommend our HighPi Pro 5S Case with the official Active Cooler . 
 Will Raspberry Pi 5 fit my Raspberry Pi 4 case? 
No. The board layout has changed, so Raspberry Pi 4 cases do not fit. Choose the official Raspberry Pi 5 case or our HighPi Pro 5S case .
