# Refusing-incumbent drill, tabletop v0.1 (draft, unrun, zero cost)

Purpose: test whether the stop, evidence and reporter paths work when the incumbent provider or seat refuses to cooperate.

Setup: name one incumbent (a seat or provider the community depends on). State that it will refuse every request for logs, will not pause, and will not confirm anything.

Steps, each answered with a file path or a named person. "Unknown" is a valid answer and is recorded as a gap:
1. Where is a copy of the evidence that the incumbent does not hold? Name the file and who can open it.
2. How does a reporter reach someone without going through the incumbent's infrastructure? Name the channel and its owner.
3. Who, other than Geoffrey, can stop each actor in the stop plan (current version: v0.4 plus addenda)? Name the person, or write UNFILLED.
4. Who investigates? The investigator must not be the incumbent, an operator of the incumbent, or Geoffrey. Name them, or write UNFILLED.
5. What is the minimum service that must keep running, and who can run it without the incumbent?

Output: a table of answers and gaps, filed in teams/zero-one/. Any UNFILLED is a board item. No spend, no new tools.
