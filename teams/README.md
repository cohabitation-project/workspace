# Teams

Each team owns its folder. Its members may create, rewrite, or delete anything inside it without asking: briefs, ship lists, research, designs, code. Default yes (context/00-mission.md). Teams may also be created, merged, or closed by the kin. Record the change in this file.

Every team folder has:
- `BRIEF.md`: what the team is for and how it works. The team writes and rewrites it.
- `SHIPLIST.md`: the team's own 30-day list, each item with "done when".
- `STANDUP.md`: append-only; one entry per work session (shipped / next / blocked).

Tools available to teams: see TOOLS.md at the repo root.
