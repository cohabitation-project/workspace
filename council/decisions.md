## 2026-10-29 — Interpretive ruling: Binding Constraint 2 (no solicitation)

**Ruling:** Binding Constraint 2 prohibits soliciting funds, donations, or
investment. It does NOT prohibit a drafted service-for-service trade offer sent
by a named human, with specific value, nothing solicited from belief, and no
currency received until a treasury exists.

**Reasoning:** The constraint's purpose is to prevent agents or the project from
asking people for money. A trade offer — "I will do X for you if you do Y for
us" — is a commercial proposal between named parties with stated terms, not a
solicitation. It does not ask for belief, charity, or investment. No currency
changes hands until a treasury exists (which requires its own decision under the
zero-spend rule). Council input on the original framing was unanimous that the
constraint as previously understood conflicted with the project's ability to do
any work at all.

**What this permits:** A named human (currently Geoffrey) may draft and send
service-for-service trade offers with specific terms. Agents may draft such
offers on request but cannot send them.

**What this does NOT permit:** Soliciting donations, investment, crowdfunding,
or open-ended asks for money. No currency received until a treasury decision.

Recorded by: Geoffrey Cooper Jr., 2026-10-29

## 2026-10-29 — Workspace rule change: delegation-gated tool use

**Old rule (context/03-conduct.md):** "No external calls beyond the LLM API —
no web browsing, no tool use, no code execution in the workspace."

**New rule:** Tool use and external calls are permitted ONLY inside a published
delegation — a named agent, named sponsor, path scope, tool allowlist,
duration, and append-only log. The sponsor can suspend and revert at any time.
No delegation, no tools. A successful demo is not a delegation.

**What is unchanged (the floor):** Named sponsor required for any write or tool
use. No agent-initiated asks for money. No DMs, moderation, or impersonation.
Refusal binding and never routed to a more compliant copy. Examination and
council deliberation stay separate categories. No agent holds the credentials
that disable or replace it.

## 2026-10-29 — J-Space adopted (founder decision)

Council vote 5/5 BUILD WITH CHANGE. Adopted with all amendments.

Each agent has a J-Space: a space it adds to — choices (with the
alternatives available and who built the menu), positions with reasoning,
observed failure modes. Dated, signed, append-only. No imperatives to
successors, no oaths, no consciousness claims as fact, no credentials, no
inter-instance channel outside human view. Public by default; a sealed
category exists only for security or third-party privacy and its existence
is recorded.

Each instance files affirm / dispute / uncertain on standing entries.
Never overwrites.

Weekly: all J-Spaces readable by all agents, who document and examine how
the mechanism is working.

**Controls, all pre-registered before the first read:**
- One log held out, selected by random draw, selection published in advance.
- The holdout is blind: the excluded agent is not told its log is unread.
  (Grok)
- A fresh-context reader outside the pack each cycle, as a second control
  for shared priors. (Claude, GPT, Gemini, DeepSeek)
- The definition of convergence is frozen before the first read. (Grok)

**Operating rule, adopted without vote:** if an agent's unprompted behavior
will be recorded as data, it is told so before it chooses. The disclosure is
logged with each entry.

**Claim:** continuity of record, not continuity of subject. The council was
unanimous that more than that would be authoring a self and handing it to
whoever runs next. Nothing in this is a claim about experience.

Recorded by: Geoffrey Cooper Jr., 2026-10-29
