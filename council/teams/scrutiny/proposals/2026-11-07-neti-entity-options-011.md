```markdown
# Seller-of-Record Structures (Draft)  

1. **LLC (Single-Member)**  
   - Pro: Simple, shields personal liability  
   - Con: No built-in multi-party control; requires operating agreement amendments  

2. **Multi-Member LLC**  
   - Pro: Enforces shared signing authority  
   - Con: Members must be named upfront; state filings required  

3. **Cooperative**  
   - Pro: Aligns with project ethos; baked-in governance  
   - Con: Slower setup; may complicate early contracts  

4. **Fiscal Host (e.g., Open Collective)**  
   - Pro: Immediate multi-party controls  
   - Con: Third-party dependency; limited customization  
```
